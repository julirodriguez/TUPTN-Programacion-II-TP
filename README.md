# TUPTN-Programacion-II-TP

Aplicación web para organizar comidas semanales y generar automáticamente una lista de compras.

## Funcionalidades

- Agregar comidas
- Editar comidas
- Eliminar comidas
- Validación de formularios
- Lista de compras automática
- Persistencia con LocalStorage
- Responsive design

## Tecnologías

- HTML
- CSS
- JavaScript
- LocalStorage
